How to Use

Manifestival lets you view IIIF Presentation API 4.0 manifest content across multiple 3D viewers. Select an example from the dropdown or paste a manifest URL into the Import URL field and click Load to fetch it. The manifest JSON will appear in the text area, where you can edit it freely. Click Load Manifest Into Viewer to render the current JSON in the selected viewer, or switch viewers using the Viewer dropdown to re-render immediately. Use Copy URL to Share View to copy a shareable link to the currently loaded manifest content to your clipboard.

FAQ

Manifestival is a tool for viewing IIIF Presentation API 4.0 manifests across multiple 3D viewers side by side. It lets you load any manifest by URL or paste JSON directly, edit it live, and compare how different viewers render the same content.

A IIIF Manifest is a JSON document that describes a digital object, such as an image, book, audio recording, video, or 3D model, and provides enough information for a compatible viewer to display it. Manifests follow the IIIF Presentation API specification.

You can load a manifest in three ways: select one from the "Select Example" dropdown to load a pre-built example; paste a URL into the "Import URL" field and click Load; or type or paste raw JSON directly into the text area. Once the manifest is in the text area, click "Load Manifest Into Viewer" to render it.

Yes. The text area is fully editable. Modify the JSON however you like, then click "Load Manifest Into Viewer" to re-render with your changes. If the JSON is not valid, the page will warn you before attempting to load.

Click "Copy URL to Share View" to copy a URL to your clipboard. If you are viewing an example or imported manifest that has not been modified, the URL will contain the original manifest URL as a iiif-content query parameter. If you have edited the JSON, the full manifest data is embedded in the URL instead, so the recipient sees exactly what you see.

Different viewers support different subsets of the IIIF Presentation API. A manifest that is valid JSON and conforms to the spec may still not render if the selected viewer does not yet implement the features it uses, for example, 3D Scenes, Audio Emitters, Activating Annotations, etc. Try switching to a different viewer using the Viewer dropdown.
